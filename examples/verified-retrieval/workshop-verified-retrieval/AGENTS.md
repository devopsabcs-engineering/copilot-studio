## Foundry workflow

This project was built with the microsoft-foundry skill. Before working on or
answering questions about foundry agents, read the microsoft-foundry skill first.

Preserve deterministic source verification, the pinned corpus, and both endpoint
authorization schemes. Activity and Invocations transport checks do not replace
native Copilot Studio acceptance.
